# 十、统一视觉规范

## 字体

当前 Figure 1/2 中部分标题具有较强的手写/圆体风格，与正文 Times 和公式字体不一致。建议统一为：

- 图内标题：Arial / Helvetica / Source Sans / Liberation Sans Bold；
- 图内正文：相同 sans-serif regular；
- 数学公式：沿用 LaTeX 数学字体；
- 最终版普通文字至少约 8–9 pt，主要标签尽量 9–10 pt。

ACL 官方建议图中文字尽可能使用正文大小，并以打印 A4 后是否清晰为标准。citeturn682573search0

## 颜色

限制在四个语义颜色：

| 语义 | 建议颜色 |
|---|---|
| reached state / context | muted blue |
| recovery / safe | green |
| harmful continuation | red |
| frozen / baseline / neutral | gray |

黄色或橙色仅用于“selected/hard/top-K”，不要同时承担方法编号、背景和警告三种功能。

## 边框

- 主模块：1.0–1.2 pt；
- 次级分组：0.7–0.9 pt；
- 不使用阴影；
- 圆角半径统一；
- 冻结模块不要只靠虚线，配合锁或雪花符号。

## 箭头

固定三类：

- 实线箭头：data/control flow；
- 虚线箭头：sampling/mining/reference-only operation；
- gradient/update 箭头：使用加粗或明确 `update` 标签。

不要让箭头颜色本身承担全部语义。

## 可访问性

- safe/harmful 除颜色外同时使用 ✓ / ✗ 或不同线型；
- 曲线图用 marker 和虚实线；
- 灰度打印后仍能区分；
- 使用矢量 PDF/SVG，不要使用低分辨率截图。ACL 官方格式也明确鼓励矢量图和灰度可读性。citeturn682573search0

## Caption

当前 Figure 2 caption 接近一个小段正文。建议 caption 只做两件事：

1. 给出 takeaway；
2. 解释图中无法自明的编码。

实现细节回到正文。

例如：

> **Figure 2: CURE-DPO first selects difficult reached states and constructs recovery–harmful continuation pairs conditioned on the identical complete state. Canonical DPO is applied per state; training updates the policy on the two highest-loss states together with clean-safety and benign anchors. Gray components are frozen.**
